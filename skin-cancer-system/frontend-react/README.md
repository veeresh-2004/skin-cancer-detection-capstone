# Skin Cancer Frontend (React + Vite)

This folder contains a converted React + Vite frontend for the Skin Cancer Detection UI.

Quick start:

1. Enter the folder:

```bash
cd frontend-react
```

2. Install dependencies:

```bash
npm install
```

3. Run dev server:

```bash
npm run dev
```

The app expects the backend predict endpoint at `http://127.0.0.1:3000/predict` (same as the original static frontend).
